# 🤖 Intro to Machine Learning – Project Collection

This repository contains three major machine learning projects, covering foundational techniques in classification and pattern recognition. Each project was completed as part of an introductory course on machine learning.

---

## 📚 Project Overview

| Project                 | Description |
|--------------------------|-------------|
| `BayesianClassifier.ipynb` | Implements a Bayesian classifier for supervised learning tasks. It models the conditional probability of classes given feature inputs and applies Bayes' theorem to make predictions. |
| `FaceRecognition.ipynb`  | Applies machine learning techniques to recognize and classify faces from images. Involves feature extraction and model training for image-based classification. |
| `SVM.ipynb`              | Trains Support Vector Machines (SVM) for binary or multiclass classification. Explores margin maximization, kernel tricks, and decision boundaries in high-dimensional spaces. |

---

## 🛠 Setup & Requirements

All projects are implemented in Python and are intended to run in a Jupyter Notebook environment.

Required packages:
- `numpy`
- `scikit-learn`
- `matplotlib`
- `opencv-python` (for face recognition)

Install all dependencies with:

```bash
pip install numpy scikit-learn matplotlib opencv-python
```

---

## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/intro-to-machine-learning.git
   cd intro-to-machine-learning
   ```

2. Open any notebook:
   ```bash
   jupyter notebook BayesianClassifier.ipynb
   ```

3. Run all cells and follow the instructions inside each notebook.
